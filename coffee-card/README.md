# כרטיס נאמנות לעגלת קפה

PWA קלה: הלקוח סורק QR בעגלה, מקבל כרטיס עם קוד QR אישי; בעלת העגלה סורקת אותו מדף הצוות (`/staff`) ומחתימה.
Cloudflare Worker (Hono) + D1. אין Wallet בשלב הזה (אפשר להוסיף Google Wallet בהמשך).

## הפעלה

```bash
cd coffee-card && npm install
npx wrangler d1 create coffee-card          # להעתיק את ה-database_id ל-wrangler.jsonc
npm run db:migrate:prod
npx wrangler secret put STAFF_PIN            # קוד כניסה לצוות (מומלץ 6 ספרות ומעלה)
npx wrangler secret put SESSION_SECRET       # מחרוזת אקראית ארוכה
npm run deploy
```

לפיתוח מקומי: ליצור `.dev.vars` עם `STAFF_PIN` ו-`SESSION_SECRET`, ואז `npm run db:migrate:local && npm run dev`.

שם העסק, נוסח המתנה ומספר החותמות נמצאים ב-`vars` ב-`wrangler.jsonc`.

## שימוש
- **ללקוחות:** להדפיס QR שמוביל ל-`https://<הדומיין>/join`.
- **בעגלה:** לפתוח `/staff` בטלפון, להיכנס עם הקוד, "סריקת כרטיס" ← "חתימה". כשיש 10 חותמות – "מימוש מתנה".
- **לקוח שאיבד את הקישור:** חיפוש לפי טלפון ב-`/staff` מציג את הכרטיס. שליחה מחדש של הקישור עדיין ידנית.

## מאפיינים
- **חותמת כפולה:** ב-`wrangler.jsonc` להגדיר `DOUBLE_STAMP_DAYS` (0=ראשון … 6=שבת, בשעון ישראל), למשל `"2"` ליום שלישי. ריק = כבוי.
- **יום הולדת:** שדה אופציונלי בהצטרפות (יום וחודש בלבד). מתנה אחת בשנה, בחודש יום ההולדת, לכרטיס בן שבוע לפחות. מומשת מדף הצוות.
- **התראת מתנה:** דף הצוות ודף הלקוח מציגים בבירור כשמתנה ממתינה.
- **ייצוא CSV:** שלושה קישורים בדף הצוות: כל הלקוחות (`/staff/export.csv`), רק מי שאישרו שיווק (`?marketing=1`), והיסטוריית חתימות (`/staff/export-events.csv`). כולם דורשים כניסה. הטלפון מופיע עם מקף (`054-1234567`) כדי שאקסל לא יבלע את האפס, והשעות בשעון ישראל. אישור שיווק בקובץ לא מחליף בדיקה שמותר לשלוח עכשיו, ועדיין אין שליחה אוטומטית.
- אחרי העלאת הגרסה הזו יש להריץ שוב `npm run db:migrate:prod`.

## חיבור דומיין (הכנה)
Worker מתחבר לדומיין מותאם דרך Cloudflare, לכן ה-DNS של הדומיין צריך להיות שם:
1. ב-Cloudflare: Add a site ← `loyaltycoffeecard.co.il` (לוודא שהאזור מתקבל; הסיומת `.co.il` לא נתמכת תמיד).
2. ב-Box ("עורך NS"): להחליף את ה-nameservers לאלה ש-Cloudflare נותן.
3. ב-`wrangler.jsonc` להוסיף `"routes": [{ "pattern": "loyaltycoffeecard.co.il", "custom_domain": true }]` ולהריץ `npm run deploy`.
לא להשתמש בהפניית 301: היא תשאיר את כתובת ה-`workers.dev` בשורת הדפדפן.

## מה מובנה
- חתימה רק עם סשן צוות חתום (HttpOnly, 12 שעות); הגבלת ניסיונות כניסה (8 ל-10 דקות לכל IP).
- הגנה מחתימה כפולה (30 שניות), הכרטיס לא עובר את המקסימום, מימוש אטומי.
- טוקן כרטיס אקראי של 128 ביט; עמוד הכרטיס חושף רק שם וחותמות.

## מגבלות ידועות
- ללא Wallet. הכרטיס נשמר כקישור או כאפליקציה במסך הבית: לכל כרטיס יש manifest משלו (`/c/<קוד>/manifest.webmanifest`) ואייקון מ-`public/`, כך שאפליקציה שהותקנה נפתחת ישר על הכרטיס. האייקון הוא הלוגו של קופילה (שלושה קבצים ב-`public/`, אפשר להחליף). אין זיהוי חוזר ב-`/join` לקוח שלא התקין ושסגר את הדף.
- מדיניות הפרטיות היא טיוטה; יש לעדכן לפני איסוף נתונים אמיתי (תיקון 13 וסעיף 30א).
- ספריות QR נטענות מ-cdnjs (נדרש אינטרנט בטלפון).
- יום ההולדת מוצהר ע"י הלקוח ולא מאומת (הגנה חלקית: כרטיס בן שבוע לפחות).
- הסריקה לא נבדקה עם מצלמה אמיתית; נבדקו ה-API וה-DB מקומית.
