# כרטיס נאמנות לעגלת קפה

PWA קלה: הלקוח סורק QR בעגלה, מקבל כרטיס עם קוד QR אישי; בעלת העגלה סורקת אותו מדף הצוות (`/staff`) ומחתימה.
Cloudflare Worker (Hono) + D1. אין Wallet בשלב הזה (אפשר להוסיף Google Wallet בהמשך).

## הפעלה

```bash
cd coffee-card && npm install
npx wrangler d1 create coffee-card          # להעתיק את ה-database_id ל-wrangler.jsonc
npm run db:migrate:prod
npx wrangler secret put STAFF_PIN            # קוד כניסה לצוות (מומלץ 6 ספרות ומעלה)
npx wrangler secret put SESSION_SECRET       # מחרוזת אקראית ארוכה
npm run deploy
```

לפיתוח מקומי: ליצור `.dev.vars` עם `STAFF_PIN` ו-`SESSION_SECRET`, ואז `npm run db:migrate:local && npm run dev`.

שם העסק, נוסח המתנה ומספר החותמות נמצאים ב-`vars` ב-`wrangler.jsonc`.

## שימוש
- **ללקוחות:** להדפיס QR שמוביל ל-`https://<הדומיין>/join`.
- **בעגלה:** לפתוח `/staff` בטלפון, להיכנס עם הקוד, "סריקת כרטיס" ← "חתימה". כשיש 10 חותמות – "מימוש מתנה".
- **לקוח שאיבד את הקישור:** חיפוש לפי טלפון ב-`/staff` מציג את הכרטיס. שליחה מחדש של הקישור עדיין ידנית.

## מה מובנה
- חתימה רק עם סשן צוות חתום (HttpOnly, 12 שעות); הגבלת ניסיונות כניסה (8 ל-10 דקות לכל IP).
- הגנה מחתימה כפולה (30 שניות), הכרטיס לא עובר את המקסימום, מימוש אטומי.
- טוקן כרטיס אקראי של 128 ביט; עמוד הכרטיס חושף רק שם וחותמות.

## מגבלות ידועות
- ללא Wallet; הכרטיס נשמר כקישור/אייקון במסך הבית.
- מדיניות הפרטיות היא טיוטה; יש לעדכן לפני איסוף נתונים אמיתי (תיקון 13 וסעיף 30א).
- ספריות QR נטענות מ-cdnjs (נדרש אינטרנט בטלפון).
- הסריקה לא נבדקה עם מצלמה אמיתית; נבדקו ה-API וה-DB מקומית.
